# Ai-Resume-Screening-System
An AI-based Resume Screening System that analyzes and compares resumes against a given job description.

✨ Features
📁 Multiple resume upload support
📄 Resume text extraction
💼 Job description processing
🧠 NLP-based text analysis
🔎 Keyword and skill matching
📊 Resume-to-job similarity scoring
🏆 Candidate ranking
⚡ Automated resume screening

🛠️ Technologies Used
-Python 3
-Natural Language Processing (NLP)
-Text Similarity
-Machine Learning concepts
-PDF/Text processing
-Scikit-learn / NLP libraries
